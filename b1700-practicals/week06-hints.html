Hint for Task 3.4: Say it carefully

A careful sentence names the variable, gives a number, says how many appearances stand behind it, and uses a tentative verb such as “tends to” or “is associated with”.

Across [n] appearances, [variable] [shape or pattern], with [group] [higher or lower] ([number]).

[Variable 1] tends to be [higher or lower] when [variable 2] is [higher or lower] (r = [number]),
but [what the plot shows about how loose or banded it is].

Avoid causes, leads to, proves, always and never.

The first anti_join() lists the rows of the first table that have no partner, and the second does the same in the other direction. left_join() keeps every row of the first table, and shows NA where there is no partner. inner_join() keeps only the rows that match.

Sanity check: three rides belong to riders who are not in riders: C91 (2 rides) and C92 (1 ride). Riders C25 and C26 have no rides. rides_joined has 122 rows, the same as rides_clean, and 3 of them have no name. inner_join() would have returned 119 rows.

Observation: evidence that a join worked is the row count and the unmatched records, not the absence of an error.

COMMON MISTAKES

Check this list if a result looks wrong.

My mean is NA

The column contains missing values. Count them with sum(is.na(x)), decide whether leaving them out is justified, and then use na.rm = TRUE. Report how many values you left out.

R says an object or function could not be found

Check the spelling and the capital letters of the column or function name, and that you have run library(tidyverse) since restarting R. IQR() is capitalised.

My histogram looks different from my partner’s

Check binwidth. A different bin width changes the picture of the same observations. State the bin width you used.

The boxplot has no boxes, or the groups are in the wrong place

The category goes on x and the number on y. If the category is stored as a number, convert it with as.factor().

R warns that it removed rows containing missing values

The plot dropped observations whose x or y value is NA. Count how many, and say so when you describe the plot.

My scatterplot shows the points in rows

The variable on one axis takes only a few distinct values, such as ratings from 1 to 5 or sprint counts in bands. Rows are a pattern in the data, not a fault in the plot.

I used geom_point() but nothing appears

Check that the + is at the end of the line, not the start of the next one, and that aes() contains both variables.

My function says it cannot find the column

Inside the function the column name needs double curly brackets: {{ column }}. Pass the name without quotes.

The correlation is strong but I am not sure what it means

A correlation describes how two variables move together. It does not show a cause, and it can hide groups. Look at the plot, and ask whether you are comparing like with like.

My left_join() has more rows than the table I started with

The lookup table has the same key more than once, so each match is repeated. Run count(key) on the lookup table, find any key with n above 1, and fix the lookup before you join.

I removed duplicates but the row count did not change

distinct() removes only rows that are identical in every column. Check duplicated() on the columns that define one row, such as the rider and the date, and look at what differs between the two rows.

pivot_longer() says it cannot combine a character and a number

You asked it to reshape the identifier column as well as the measurements. Choose only the measurement columns, for example cols = starts_with("ftp").

I changed tracking and cannot get the original back

Run the import line again. In future, store new tables in new objects so that the original stays available for comparison.
