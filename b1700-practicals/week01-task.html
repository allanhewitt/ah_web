Understanding Data and R

Group Task Sheet · Core → Transfer → Extension

WHY THIS MATTERS

Central question: What does our data mean, and how is R representing it?

R can execute an operation correctly even when the operation is analytically meaningless. R knows the representation; the analyst has to understand the meaning.

How to work this week

Work through this page in order as a small group. This task page is your activity script.

Use the supplied Week 1 RStudio project as your shared workspace. It contains the datasets, setup code and labelled spaces for each phase. Decide together what analysis or code is needed, and keep brief notes or comments in the R script as you work. The R file is not a completed solution.

If your group gets stuck, open the Week 1 Hint Sheet and use the hint for the relevant task. Try to return to the task before reading ahead.

For this first session, use one active RStudio project per group and rotate the person operating RStudio at least once during the activity. Everyone should be able to explain the group's decisions.

PHASE 2 — CONSEQUENCE PROBLEM

Now test whether your distinction between representation and meaning actually matters.

Task 2.1 — Judge the analysis

A colleague reports the mean squad number for a team and suggests that this describes the squad. R has performed the calculation correctly.

As a group: Decide whether the analysis is meaningful. What has R done correctly, and what judgement has the analyst failed to make?

Record: Write a short group response in the Phase 2 section of the R script.

PHASE 3 — CORE PRACTICAL

Use the Strathclyde FC squad data to investigate how R represents variables and how that differs from analytical meaning.

Task 3.1 — Establish the grain

Open the Week 1 RStudio project and inspect the squad data.

As a group: Agree what one row represents.

Record: Write one clear sentence in the R script.

Task 3.2 — Compare role and representation

Focus on player_id, squad_number, age and position.

As a group: For each variable, compare its analytical role with the way R represents it. Identify any case where relying on the R class alone could encourage a poor analytical decision.

Record: Add a brief role-versus-representation note for each variable.

Task 3.3 — Choose a sensible summary for age

As a group: Produce a small set of numerical summaries that help describe the ages in the squad. Decide which summaries are useful and what each contributes.

Record: Save the output you need and add a short interpretation.

Task 3.4 — Choose a sensible summary for position

As a group: Summarise the squad's playing positions in a way that respects the meaning of the variable.

Record: Add the result and one sentence explaining why this form of summary is appropriate.

Task 3.5 — Revisit the squad-number problem

As a group: Ask R for the mean squad number, then interpret the result critically.

Record: Write one sentence explaining why a technically valid calculation can still be analytically unhelpful.

PHASE 4 — CHECKPOINT

Pause before moving to a new dataset.

Task 4.1 — State the rule you are using

As a group: Agree on a short set of principles that would help an analyst avoid confusing storage type with analytical meaning.

Record: Write four concise bullet points covering:

  • what one row represents;
  • identifier, category, quantity and logical variables;
  • representation versus analytical meaning;
  • choosing a summary because it suits the variable and question.
PHASE 5 — TRANSFER

Apply the same reasoning to an unfamiliar sport and a fresh set of variables.

Task 5.1 — Audit the swimming data

Open week01_transfer_swimmers.csv using the supplied RStudio project.

As a group: For each variable, decide:

  • what it means;
  • its analytical role;
  • how R represents it;
  • one operation that would make analytical sense;
  • one operation that would be misleading or meaningless.

Record: Keep a concise representation audit in the Phase 5 section of the R script.

Task 5.2 — Identify what transferred

As a group: Compare your reasoning on the football and swimming datasets. What did you do the same even though the sport and variables changed?

Record: Write one or two sentences identifying the transferable analytical principle.

PHASE 6 — EXTENSION

Use this if your group completes the core and transfer work comfortably.

Task 6.1 — Challenge the default representation

As a group: Identify any swimming variable where its R class could tempt an inexperienced analyst into the wrong interpretation. Decide what, if anything, you would change, what you would leave unchanged, and why.

Record: Add a short representation audit. The focus is the quality of your judgement, not the number of functions used.

PHASE 7 — DEBRIEF

Finish by articulating the principle that should carry into later weeks.

Task 7.1 — Complete the takeaway

As a group: Complete the sentence together:

Before analysing a variable, an analyst needs to know …

Record: Add your final sentence to the R script.
