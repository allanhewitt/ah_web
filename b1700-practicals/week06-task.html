Describing and Communicating Evidence

Group Task Sheet · Core → Transfer → Extension

Why this matters

Central question: What does the evidence show, and how should we represent it?

Statistics and visualisations are selective representations of reality. A technically correct summary can still provide a misleading or incomplete account of the evidence.

How to work this week

Work through this page in order as a small group. Use the Week 6 RStudio project and keep notes in week06_session.R. Choose summaries and plots because they serve the question, not because they are familiar.

If your group gets stuck, use the Week 6 Hints selectively, then return to the task.

PHASE 1 — RETRIEVAL

Carry the earlier analytical checks into description and visualisation.

Task 1.1 — Recall the checks that still matter

As a group: Before producing a statistic or graph, answer: What does one row represent? Is the variable meaningful for the intended operation? Have missing or implausible values been considered? If data were joined, how would you verify that the grain was preserved?

Record: Write four brief reminders in the Phase 1 workspace.

PHASE 2 — CONSEQUENCE PROBLEM

Consider what is lost when evidence is compressed.

Task 2.1 — Compare two technically correct summaries

Two analysts use the same observations. One reports only a mean; the other shows the distribution and spread as well.

As a group: Do they communicate the same evidence? What can a single summary hide?

Record: Write a short response focused on what is revealed and obscured.

PHASE 3 — CORE PRACTICAL

Move from numerical description to visual representation and cautious communication.

Task 3.1 — Describe centre and spread

The project loads player_match_tracking.csv directly as analysis_data; no joining is required.

As a group: For distance_km, calculate mean, median, standard deviation, IQR and selected quantiles. Explain what centre and spread each contribute.

Record: Keep the summaries and a concise interpretation of centre versus spread.

Task 3.2 — Inspect the distribution visually

As a group: Create a histogram of distance_km. Change the bin width once. Decide which features appear robust and which visual features change.

Record: Keep both visual checks and a brief comparison.

Task 3.3 — Compare positions without reducing them to means

As a group: Calculate a small table of centre and spread by position, then create a boxplot of distance by position. Decide what the plot reveals that group means alone do not.

Record: Keep the summary, plot and one-sentence comparison.

Task 3.4 — Describe a relationship before explaining it

As a group: Create a scatterplot of distance_km against sprints. Describe the observed relationship before offering any explanation.

Record: Write a cautious description of direction, strength and shape.

Task 3.5 — Separate association from causation

As a group: Explain why the scatterplot does not establish that one variable causes the other.

Record: Write a one-sentence causal qualification.

Task 3.6 — Make the visual communication purposeful

As a group: Add a clear title and axis labels to your plots and use theme_minimal(). Make sure the labels help a reader understand the analytical question.

Record: Keep one polished plot that could be shown to another reader.

Task 3.7 — Write for a coach

As a group: Choose one result and write a two-sentence interpretation for a coach. Include one limitation or qualification.

Record: Write the two-sentence interpretation.

PHASE 4 — CHECKPOINT

Choose a representation from the question and variable structure.

Task 4.1 — Checkpoint the visual framework

one numeric variable → histogram
numeric + category → boxplot
two numeric variables → scatterplot

As a group: Explain why this is a starting framework rather than a rule to plot by habit.

Record: Write one sentence linking representation choice to the analytical question.

PHASE 5 — TRANSFER

Apply the visual reasoning to a fresh performance question.

Task 5.1 — Identify the variables and representation

Open week06_transfer_swimming.csv. A coach asks: “Do swimmers with higher recent training loads tend to record faster race times?”

As a group: Identify the core variables and choose an appropriate visual representation.

Record: Record the variables and why the representation fits them.

Task 5.2 — Produce the evidence you need

As a group: Produce the scatterplot and any descriptive summaries that help you understand the variables or event groups. Use summaries already introduced this week; a correlation coefficient is not required.

Record: Keep the useful plot/summaries only.

Task 5.3 — Describe the observed relationship cautiously

As a group: Describe what the plot shows without overstating the pattern.

Record: Write a short evidence-first description.

Task 5.4 — Reject an unwarranted causal claim

As a group: Explain why this evidence does not establish that training load caused faster performance.

Record: Write a causal qualification.

Task 5.5 — Interrogate the pooled comparison

As a group: Identify why mixing event groups with very different race-time scales complicates the pooled relationship. Explain what you would want to inspect next.

Record: Write the limitation and next analytical step.

PHASE 6 — EXTENSION

Explore how presentation can change interpretation without changing observations.

Task 6.1 — Create two defensible representations

As a group: Create two technically valid representations of the same Strathclyde FC comparison that emphasise different features of the evidence. Explain which you would use for a coach, what each reveals or obscures, and how presentation choices can alter interpretation.

Record: Keep both representations and your recommendation.

PHASE 7 — DEBRIEF

Finish by making the representational nature of graphs explicit.

Task 7.1 — Complete the statement

As a group: Complete the statement: A graph is not the data; it is …

Record: Write one final sentence in the R script.
Assessment One connection: centre/spread, histogram, boxplot, scatterplot, basic labels/themes and cautious interpretation are core. Density plots, jitter, faceting and advanced factor handling are extension.
