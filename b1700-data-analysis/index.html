B1700 Introduction to Sport Data Analytics

Data Analysis: Weeks 1 to 6

A six-week journey from understanding what data mean to producing and communicating defensible evidence in R.

The first six weeks build one analytical workflow. Each week adds a new layer, but the central principle remains the same: R can perform operations, while the analyst remains responsible for meaning, judgement and interpretation.

01
Understand

Understanding Data and R

What does our data mean, and how is R representing it?

You learn to

Identify what one row represents, distinguish identifiers, categories, quantities and logical variables, inspect R types, and judge whether an operation makes analytical sense.

Key idea: technically valid code is not necessarily analytically meaningful.

Core R

head()
glimpse()
class()
mean()
table()

02
Trust

Importing Data and Establishing Trust

Did the data enter R correctly, and should we trust what came in?

You learn to

Import and inspect data, check dimensions and types, identify missing or implausible values, verify identifier coverage, and distinguish what has been established from what remains uncertain.

Key idea: trust is established, not assumed.

Core R

read_csv()
nrow()
ncol()
names()
is.na()
%in%

03
Transform

Asking Questions and Transforming Data

What are we trying to find out, and what must happen to the data to answer it?

You learn to

Translate a plain-language analytical question into a sequence of operations, decide which observations matter, derive new measures, group data and create summaries that match the question.

Core workflow: question → filter → derive → group → summarise → interpret.

Core R

|>
filter()
mutate()
group_by()
summarise()
n()

04
Clean

Diagnosing and Cleaning Data

What is genuinely wrong, and what change is defensible?

You learn to

Diagnose missingness, implausible values, duplicates and inconsistent categories, make defensible cleaning decisions, reshape data where necessary, and verify what changed afterwards.

Core workflow: diagnose → decide → clean → verify.

Core R

is.na()
if_else()
distinct()
str_trim()
case_when()
pivot_longer()

05
Connect

Connecting Data Sources

What if the evidence we need is spread across different tables?

You learn to

Identify table grain and keys, decide what observations must be preserved, join data deliberately, diagnose unmatched records and verify that the resulting table still represents what you think it represents.

Key idea: a join is part of the analytical argument, not just a technical merge.

Core R

left_join()
anti_join()
inner_join()
nrow()
is.na()

06
Describe & Communicate

Describing and Communicating Evidence

What does the evidence show, and how should we represent it?

You learn to

Choose numerical summaries and plots that match the question, describe centre and spread, compare groups, recognise associations and communicate evidence without overstating what the data support.

Key idea: every statistic compresses, and every plot directs attention.

Core R

mean()
median()
sd()
IQR()
ggplot()
geom_histogram()
geom_boxplot()
geom_point()

The six-week lesson

R can import, transform, clean, join, calculate and plot. It cannot decide what a variable means, whether evidence is trustworthy, which question matters, whether a cleaning decision is defensible, whether a join preserves the intended grain, or what conclusion is justified.
